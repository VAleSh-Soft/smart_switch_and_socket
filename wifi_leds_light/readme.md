## wifi_leds_light
WiFi-модуль для управления светодиодной лентой, построенный на основе **esp8266** или **esp32**.

### Устройство модуля

Светодиодная лента управляется с помощью мосфета N-типа, никаких электромеханических реле не используется. Управление построено на двух [виртуальных реле](https://github.com/VAleSh-Soft/shSRControl#виртуальные-реле), позволяющих включать и выключать ленту как плавно (примерно 5 секунд на розжиг), так и обычным образом.

Модуль имеет одну локальную кнопку, которая подвязана ко второму виртуальному реле и включает/выключает ленту обычным образом. Плавный запуск ленты возможен с помощью Web-интерфейса, встроенного [планировщика задач](https://github.com/VAleSh-Soft/shSRControl#планировщик-задач), либо с помощью WiFi-выключателя, настроенного на первое виртуальное реле.

Модуль управляет одной лентой.

### Файловая система

В файловой системе модуля сохраняются конфигурационные файлы, нужные для его работы.

За инициализацию и первичное форматирование файловой системы отвечает библиотека [shESPFSinit](https://github.com/VAleSh-Soft/shESPFSinit).

По умолчанию тип файловой системы автоматически выбирается в зависимости от используемого МК: для **ESP32** используется **FFat**, для **ESP8266** - **LittleFS**. Однако, в обоих случаях можно использовать старую файловую систему **SPIFFS**, или **LittleFS** для **ESP32**. Подробнее о ручном выборе файловой системы можно посмотреть [здесь](https://github.com/VAleSh-Soft/shESPFSinit#указание-типа-файловой-системы).

Для **ESP32** в опциях платы нужно выбрать в **Partition cheme** схему **Default 4MB with ffat** для **FFat** или **Default 4MB with spiffs** в остальных случаях; если у вас плата с 16 Мб флеша, то нужно выбирать соответствующую опцию.

Для **ESP8266** в опциях платы ничего дополнительно выбирать не нужно

В случае **ESP32** форматирование файловой системы выполняется автоматически при  самом первом запуске или при первом запуске после изменения типа файловой системы; после форматирования модуль автоматически перезагружается;

### Обновление прошивки

В модуле есть возможность обновления прошивки "по воздуху" с использованием Web-интерфейса. Доступ к интерфесу обновления выполняется по адресу "/firmware", однако адрес можно изменить в функции `server_init()` в файле **header_file.h**
```
// настройка сервера обновлений
httpUpdater.setup(&HTTP, "/firmware");
```
Дополнительно в этом методе можно задать логин и пароль для доступа к интерфейсу обновления.

В интерфейсе обновления нужно выбрать файл с новой прошивкой, нажать на кнопку **Update firmware** и дождаться результата.

### Подключение периферии

Пины для подключения кнопок и светодиодной ленты указаны в файле **header_file.h**

### Использованные сторонние библиотеки

- [shSRControl](https://github.com/VAleSh-Soft/shSRControl) - работа с релейными модулями;
- [shWiFiConfig](https://github.com/VAleSh-Soft/shWiFiConfig) - настройка параметров WiFi-соединения;
- [shESPFSinit](https://github.com/VAleSh-Soft/shESPFSinit) - иницициализация файловой системы ESP;
- [shTaskManager](https://github.com/VAleSh-Soft/shTaskManager) - диспетчер задач;
- [ArduinoJson](https://github.com/bblanchon/ArduinoJson) (код писался с использованием версии 6.21.3) - работа с текстом в формате JSON;
